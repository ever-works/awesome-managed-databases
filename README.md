## Edge / SQLite Databases

- [Cloudflare D1](https://developers.cloudflare.com/d1) - Serverless SQL database running on Cloudflare's edge network, built on SQLite. Integrates with Workers and offers a free tier with paid usage tiers. ([Read more](/details/cloudflare-d1.md)) `Free Plan` `Freemium` `Edge` `SQLite` `Cloudflare` `Serverless`
- [LibSQL](https://libsql.org/) - Open-source fork of SQLite with client/server architecture and replication, managed by the Turso team. Can be self-hosted or used with Turso cloud. ([Read more](/details/libsql.md)) `Open Source` `Self-Hosted` `SQLite` `libSQL` `Edge`
- [Turso](https://turso.tech/) - Edge-hosted distributed SQLite database based on libSQL, designed for low-latency access close to users. Offers a free tier and usage-based paid plans. ([Read more](/details/turso.md)) `Free Plan` `Freemium` `Edge` `SQLite` `libSQL` `Serverless`

## Serverless Postgres

- [Neon](https://neon.tech/) - Serverless Postgres with storage and compute separation, branching, and autoscaling. Designed for developers needing instant provisioning and scale-to-zero. Offers a generous free tier and paid plans. ([Read more](/details/neon.md)) `Open Source` `Self-Hosted` `Free Plan` `Freemium` `API` `Serverless`
- [Nile](https://nile.dev/) - Postgres platform designed for multi-tenant applications with virtual tenant databases and tenant-aware scaling. Offers a free tier and paid plans for SaaS developers. ([Read more](/details/nile.md)) `Free Plan` `Freemium` `Multi-tenant` `API` `Serverless`
- [Prisma Postgres](https://prisma.io/postgres) - Serverless Postgres database built by Prisma with integrated connection pooling and Prisma ORM support. Targets application developers seeking a managed Postgres experience with a free tier. ([Read more](/details/prisma-postgres.md)) `Free Plan` `Freemium` `API` `ORM` `Serverless`
- [Supabase](https://supabase.com/) - Open source Firebase alternative built on PostgreSQL, providing authentication, storage, and realtime APIs. Suitable for backend-as-a-service use cases with a free tier and paid usage plans. ([Read more](/details/supabase.md)) `Open Source` `Self-Hosted` `Free Plan` `Freemium` `API` `BaaS`
- [Xata](https://xata.io/) - Serverless Postgres database with built-in search, vector search, and AI capabilities. Provides a generous free tier and scalable paid plans for AI-powered applications. ([Read more](/details/xata.md)) `Free Plan` `Freemium` `AI-Powered` `API` `Search` `Serverless`
